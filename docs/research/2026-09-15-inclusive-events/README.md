## Формат и почему такой

**Как делался прошлый сид.** Контент МСК/СПб 24.08 загружали не скриптом и не SQL: скрипта в репо нет. События заводились через приложение (`POST /api/v1/events`) от лица организатора **«Редакция PRESENCE»**. Это видно по раннбуку `docs/superpowers/runbooks/2026-08-23-spb-city-launch-deploy.md`, разделы «Контент СПб / МСК / Обложки»:
- на время загрузки поднимали `EVENTS_MONTHLY_LIMIT` 10→100 и потом возвращали;
- обложки прикрепляли через edit-форму: форма сама делает upload и `cover_file_id`;
- регистрация внешняя: `signup_mode=external`, ссылка с whitelist-домена.

Поэтому каждая запись `events.json` содержит готовое тело **`EventInput`** (`backend/api/swagger.yaml`) и рядом данные, которые разрешаются при загрузке.

| Поле записи | Что это |
|---|---|
| `event_input` | Тело для `POST /api/v1/events`. `status: "published"`, `format: "offline"`, `signup_mode: "external"`, `price_type` ∈ `free/fixed/from`, `price_min/max` в **целых рублях** (форматтер бэкенда превращает 0 в null, поэтому «от 0» не выразить). `starts_at/ends_at` в RFC 3339 +03:00. `city` ∈ `msk/spb`: при заданной площадке город берётся из venue, конфликт даёт 400. |
| `event_input.venue_id`, `category_ids`, `cover_file_id` | `null`/пусто. Заполняются при загрузке: id площадки ищется или создаётся, id категорий берутся из `GET /categories` по слагу, обложка грузится через upload. |
| `category_slugs` | Слаги из `categories`: `lecture, workshop, mediation, concert, exhibition, performance, film, festival, reading-group, walk`. Отдельной категории «инклюзия» нет: доступность описана в `description` и `meta.accessibility`. |
| `venue` | `catalogue_match`: имя площадки из репо-каталога (`backend/db/seed/seed.sql` + `docs/research/venues_seed*.json`, всего 172 строки), либо `is_new: true` с адресом для геокодинга. Новую площадку можно завести `POST /api/v1/venues` (`VenueInput`: name, address, city, lat/lon; find-or-create по имени) или по образцу `venues_seed_2.sql`. |
| `meta` | `source_url` — где проверено. `registration_url_whitelisted`, доступность, `cover_image_url` для ручной загрузки, возраст, заметки. |

### Важные особенности при загрузке

1. **Whitelist (`trusted_platforms`).** Внешняя ссылка с домена вне whitelist не блокируется, но переводит событие в **`pending_review`**: админ одобряет. Таких событий 9 (`registration_url_whitelisted: false`): ссылки на сайты музеев и театров, specialviewportal.ru, forms.yandex.ru, zapomni.ru. Варианты: одобрить в модерации, добавить домен в whitelist или заменить ссылку на KudaGo/Timepad-страницу, если она найдётся.
2. **Гигиена.** Регэксп `QA|тест|test` по названию не срабатывает ни на одном событии. Цены далеки от порога «подозрительной цены».
3. **Лимиты.** 21 событие больше `EVENTS_MONTHLY_LIMIT=10`. Как и 24.08, лимит нужно временно поднять или грузить в два захода.
4. **Время окончания.** Где `ends_at` = null, время окончания неизвестно.
