# timepad-ingest — сбор анонсов с TimePad

Второй сборщик после `tools/tg-ingest`. Первый источник — Европейский
университет в СПб (`eusp.timepad.ru`). Ничего не публикует: готовит черновики
на проверку редактору.

## Почему по HTML, а не через API

`api.timepad.ru/v1` требует токен из личного кабинета организатора (без него
403), а у нас его нет. Страница организатора отдаёт все события server-side и
без ключа — этого достаточно.

## Запуск

```bash
python3 ingest.py             # горизонт 90 дней
python3 ingest.py --days 30
python3 ingest.py --all       # включая уже импортированные
```

Результат в `out/`:
- `candidates-<дата>.json` — тела для `POST /api/v1/events`, всегда `status: draft`;
- `unsure-<дата>.json` — спорные по теме, с такими же готовыми телами;
- `review-<дата>.md` — для чтения глазами: три корзины и причины отказов.

Зависимостей нет, только стандартная библиотека.

## Правила, заданные владельцем

1. **Конференция — одно событие на весь диапазон дат.** Её сессии в отдельные
   события не разворачиваются, они идут в отчёт. Признак: многодневная
   программа либо слово «конференция / чтения / симпозиум / съезд» в названии.
   Серия семинаров конференцией не считается: у каждого своя дата и тема.
2. **Три корзины, а не бинарный отсев.** Подходящие по теме площадки (искусство,
   культура, сообщество, история) — в `candidates`, спорные — отдельным списком
   с готовыми телами, отброшенные — с причиной. Решает редактор.

## Две ловушки, найденные при разработке

1. **Года в датах на страницах нет, и вычислять его самому нельзя** — ошибка
   превращает прошедшее событие в будущее. В списке TimePad у каждой карточки
   есть своя пометка: «через 13 дней», «69 дней назад», «идет сейчас». Её и
   используем как признак прошлого/будущего.
2. **Карточки режем по границам `t-card_event`, а не окном вокруг ссылки.**
   Окно захватывало соседнюю карточку и сдвигало дату на одно событие: «Язык,
   или Главная загадка человечества» получил 30.09 вместо 2.10. После правки
   все пять дат совпали со страницами самих событий.

## Проверка (2026-09-19)

Из 20 событий ЕУ: 4 подходящих, 1 спорное, 15 отброшено (14 прошедших плюс два
городских экономических семинара — они вне темы площадки; один из прошедших
попал в обе причины). Даты всех пяти отобранных сверены со страницами событий —
совпадение полное.

**Важно про разметку из хэндофа:** она делалась по всему списку без учёта дат.
К 19.09 большинство «подходящих» оттуда уже прошло (июль–середина сентября), и
реально к импорту остаются презентации книг, семинар о республиканизме и
конференция «Холодное лето — 2026».

Классификация по ключевым словам не воспроизводит разметку владельца один в
один: презентации книг Щербака и Бочарова он относил к спорным, а сборщик по
слову «книга» кладёт их в подходящие. Это не ошибка кода, а граница метода —
поэтому всё и уходит черновиками на просмотр.

## Что редактор доделывает руками

- **Описание.** Скрипт его не пишет: авторский текст анонса идёт только в отчёт
  цитатой, редактор пересказывает своими словами (та же политика, что в tg-ingest).
- **Обложки.** Постеры лежат на `ucare.timepad.ru`, права у площадки —
  автоматически не перезаливаем, в отчёте только ссылка.
- **Цена.** Берётся из разметки билетов (`"price":0` — бесплатно). Если цены на
  странице нет, ставится «бесплатно» с пометкой «проверить».

Источник проставляется автоматически: `source_url` — страница TimePad,
`source_label` — «TimePad Европейского университета» (поля из миграции 29).
