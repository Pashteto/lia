## Что сделано

### 1. Атрибуция источника (выкачено)

Площадки разрешили републиковать свои анонсы **при условии ссылки на источник в каждом событии**.
Класть её было некуда: происхождение держалось на организаторе «Редакция PRESENCE» и на
`external_registration_url` — а это другое поле, оно про запись и проверяется по белому списку
платформ. Telegram в белом списке нет, поэтому ссылка на канал в этом поле отправляла бы каждое
импортированное событие на модерацию.

Миграция 29: `events.source_url` + `events.source_label`, обе `TEXT NOT NULL DEFAULT ''`
(как `curator_question` и `external_registration_url` из миграции 12 — пустая строка уже значит
«источника нет», и go-pg не надо учить читать NULL в string).

Проводка: модель + `validateSource()` (подпись без ссылки — ошибка, только http/https) +
`NormalizeSource()` (пустая подпись ← хост; вызывается в `Create` и `Update` перед `Validate`);
swagger ×3 + `make generate-api`; форматтер (вход, патч, ответ); `events.UpdateParams`;
`internal/http/admin/handler.go`. Фронт: `lib/types.ts`, `lib/api.ts`, блок «Источник» в
`EventDetailView` под описанием, пара полей в `CreateEventForm` с проверкой пары,
проброс в `app/events/[id]/edit/page.tsx`, «Источник анонса» в карточке `AdminModeration`.

Сознательно **не** сделано: обязательность источника в БД (у событий от самих организаторов его
нет и быть не должно) и ретро-заполнение 87 ранее импортированных событий.

## Грабли, которые стоили времени (не наступать снова)

1. **`Update` в `internal/events/repository.go` пишет по ЯВНОМУ списку колонок.** Новые колонки
   надо дописывать туда руками, иначе `Create` значение пишет, а правка молча теряет. Поймано
   только на проде: у пути обновления нет юнит-тестов, нужна БД. Фикс — `5393706`.
2. **Общий чекаут на три сессии.** `docker build` берёт рабочую папку, а `git commit` без путей
   коммитит **весь индекс**, включая чужое (уже утащил файлы соседней сессии — пришлось переписывать
   локальные коммиты). Правило: собирать из `git worktree add /tmp/deploy-src <sha>`, коммитить
   `git commit -F - -- <пути>`, перед сборкой проверять `git status --short frontend/ backend/`.
3. **В worktree нет сгенерированного кода** (`internal/http/models/`, `protocols/*.pb.go` в
   `.gitignore`): нужен `make generate-api` и копирование `protocols/userservice/*.pb.go` из
   основного дерева, иначе сборка падает на отсутствующем пакете.
4. **`EVENTS_MONTHLY_LIMIT` считает ВСЕ события «Редакции PRESENCE» за месяц** (в сентябре их ~50).
   Каждый импорт упирается в 429 и требует поднять лимит и вернуть обратно. За сентябрь это делалось
   трижды — для регулярного импорта нужен отдельный лимит или отдельный организатор-бот.
5. **Разбор дат.** «18.09 20:00» читается как время 18:09 — различать по второму числу (у времени
   `00` или больше 12). Подпись «двери» может стоять ПОСЛЕ времени. На TimePad года в датах нет
   вообще: не вычислять, а брать пометку «через N дней / N дней назад / идет сейчас».
   Карточки списка резать по контейнеру `t-card_event`, иначе дата съезжает на соседнее событие.

## Постоянные ограничения

- **Описание пишет редактор своими словами.** Факты переносим, авторский текст и фотографии — нет.
- **Импорт приземляется черновиком/на модерацию, не в ленту.** Разбор свободного текста ошибается
  на датах, ценах и адресах.
- **Обложки из чужих постов** ставим только с разрешения автора; постеры TimePad не перезаливаем.
- **Прод в Telegram не ходит** и VPN на боевом хосте не нужен: сборщики живут снаружи.
