# Партисипаторные события — подборка для афиши (2026-09-15)

20 реальных событий: **МСК 11, СПб 9**, 17.09–29.10.2026. Отбор — участие посетителя в культурном событии: медиации, мастерские и лаборатории (в том числе с художниками), читательские группы и книжные или дискуссионные клубы, визиты в мастерские художников, коллективная импровизация и вокальная лаборатория для непрофессионалов. Каждое событие проверено на странице первоисточника: сайт институции, KudaGo (публичный API), страница площадки на Timepad. Дедуп проведён против живых событий (`ev_msk/ev_spb.json`) и инклюзивной подборки `docs/research/2026-09-15-inclusive-events/`: пересечений нет. Данные собраны только публичными GET-запросами; ни БД, ни сервер, ни API записи не затрагивались.

Файлы:
- `events.json` — сид в том же формате, что и инклюзивная подборка.

## Формат

Как в `docs/research/2026-09-15-inclusive-events/README.md`. Каждая запись содержит:
- `event_input` — тело для `POST /api/v1/events` (`status: published`, `signup_mode: external`, цены в целых рублях, при `free` поля `price_min/max` опущены, время в RFC 3339 +03:00, `ends_at: null`, если окончание не объявлено);
- `category_slugs` — существующие слаги;
- `venue` — либо `catalogue_match` + `prod_venue_id` из снапшота прод-каталога (`part/v_msk.json`, `v_spb.json`), либо `is_new: true` с адресом;
- `meta` — поля `source_url`, `registration_url_whitelisted` (посчитано суффикс-матчингом по 22 доменам миграции `000026_trusted_platforms`), `participation` (как участвуют посетители), `cover_image_url`, `age`, `notes`.

Отличие от инклюзивного сида: вместо `meta.accessibility` используется `meta.participation`.

`key` = `part-01…` по времени начала.
