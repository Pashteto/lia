# ges2-ingest — дискуссионные и инклюзивные события ГЭС-2

Третий сборщик после `tg-ingest` и `timepad-ingest`. Источник — календарь
ges-2.org. Telegram-канал ГЭС-2 (@vacges2) для импорта не годится: он
редакционный, анонсов с датой там почти нет.

## Откуда данные

Сайт на Next.js ходит в открытый GraphQL `https://ges-2.org/graphql`. Тот же
запрос `calendarItems`, что строит страницу календаря, принимает список дат и
отдаёт по каждой встрече: время на этот день (`calendarHours`), формат
(`subtype`), цену, кнопку регистрации (zapomni.ru) и пометки доступности.
Токен не нужен.

## Что отбирается

| Корзина | Форматы | Правило |
|---|---|---|
| разговорные | беседа, лекция, дискуссия, кинопоказ с обсуждением, книжный клуб | всегда |
| инклюзивные | туры, лаборатории, концерты, кино, игры, мастер-классы, перформансы | только с пометкой «Доступно глухим/незрячим» |
| спорные | публичная программа (там и разговоры, и йога), любые серии | решает редактор |
| никогда | выставки, инсталляции, платные мастер-классы в «Сводах», йога | — |

Настраивается в `config.json` → `subtypes`, `never`, `skip_titles`.

## Две ловушки

1. **Серии.** Медиаторские туры и лаборатории идут по много раз в месяц, а
   дата старта у материала старая (2022 год). Время конкретной встречи — только
   в `calendarHours` на этот день. Серию (3+ встречи в окне) сборщик предлагает
   одной ближайшей встречей в спорные; если серия уже есть в афише или в
   state — не предлагает вовсе.
2. **Пометка доступности общая.** «Доступно глухим и слабослышащим» стоит на
   всём материале, а точный формат (РЖЯ, тифло, запись через access@ges-2.org)
   написан в тексте страницы (`verstkaDesktopHtml`). Сборщик вытаскивает эти
   фразы в отчёт; редактор выносит формат в название или первую фразу
   описания — отдельного поля доступности у события нет.

## Запуск

```bash
python3 ingest.py             # горизонт 30 дней
python3 ingest.py --days 60
python3 ingest.py --all       # включая уже импортированные
```

Результат в `out/`: `candidates-*.json`, `unsure-*.json` (тела `POST /api/v1/events`,
`status: draft`) и `review-*.md`.

## Публикация

- Описание пишет редактор своими словами; текст ГЭС-2 — только в отчёте.
- Обложка — логотип ГЭС-2 (`tools/venue-covers/ges2.jpg`, id в `config.json`),
  фото с сайта не перезаливаем.
- Ссылки регистрации ведут на zapomni.ru, его нет в whitelist платформ:
  событие уходит в `pending_review`, админ одобряет
  (`POST /admin/moderation/events/{id}/approve`) или домен добавляется в whitelist.
- После импорта записать `ges2/<material id>/<дата>` → id события в `state.json`.
