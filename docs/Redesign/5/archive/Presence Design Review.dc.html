Foundations · cross-cutting

Fix these once and every page improves

The single biggest issue is the absence of a visual system — the site reads as an unstyled scaffold. A warm, editorial identity (rounded shapes, one display face, a category color system) does most of the work before any page-level redesign.

A

The event card — the atom of the whole product

Every list, the map and the calendar are made of this card. Today it's a single run-on string; giving it structure, a category color, a thumbnail and a clear price is the single most repeated win.

B

A category color system

Assign each category one persistent color from the Organic ramps. It makes lists scannable, ties the map pins to the legend, and lets a card telegraph its type before you read a word. Keep two accents doing the heavy lifting; use neutral for the calmer categories.

C

Navigation with a spine

Give the top bar a brand mark and a visible active state on desktop; on mobile, move primary destinations to a bottom tab bar within thumb reach.

Issues
  • One column of undifferentiated text links — nothing to scan or compare.
  • Filters mix time (Сегодня), category (Лекции) and location (Рядом со мной) on one row with no active state.
  • No result count, no sort, no sense of «where/when» at a glance.
  • Categories in cards (Кино, Концерты) aren't filterable.
Recommendations
  • A responsive card grid with thumbnail, date badge, category color and price.
  • Split filters into two rows: time/quick chips, then categories; show the active one filled.
  • Add a result count and a sort control; complete the category set.
  • Group by day («Сегодня», «Завтра», «На выходных») as an alternative to a flat list.

  • No clear hero, no single obvious «Записаться» action.

Подбор — AI-ассистент

Current: prints a developer placeholder with a source path. This is your strongest differentiator — design it for real.

Issues
  • Shows «ещё не реализовано… Смотри design/screens/ai-search.html» to users.
  • A dead end — no fallback to manual search, no example of what it can do.
  • No entry point from the feed, where intent actually forms.
Recommendations
  • A conversational prompt with seed suggestions («тихое на выходных», «бесплатно рядом»).
  • Answer as a short sentence + real event cards, each explaining the match.
  • Always offer «точные фильтры» as a fallback so it's never a dead end.
  • Until the model ships, ship a smart filter form here — never a raw TODO.

Where to start

A pragmatic order to work in

You don't need everything at once. Ship in this order and each step makes the next cheaper.

1 · Hygiene (days)

Remove the dev note and QA/test events from production. Fix the filter taxonomy and add the missing category. Zero-cost credibility.

2 · The card + identity (1–2 wks)

Adopt the Organic system, rebuild the event card and category colors. This lifts the feed, map and calendar in one move.

3 · Detail + AI-подбор (2–4 wks)

Design the conversion screen and turn Подбор into a real flow (or a smart filter fallback). Then round out organizer tools and states.
