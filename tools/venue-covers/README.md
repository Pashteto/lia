# Обложки площадок

Изображения, которые получают импортированные события без своей картинки.
Загружены на прод 2026-09-29; `cover_file_id` прописаны в
`tools/tg-ingest/channels.json` и `tools/timepad-ingest/config.json`.

| Файл | Площадка | Что это | cover_file_id |
|---|---|---|---|
| `eusp.jpg` | Европейский университет | официальная og-картинка сайта eusp.org с логотипом | `aff87a29-ba64-401d-a197-3c913468d0e9` |
| `nefiktiv.jpg` | «Нефиктивное образование» / галерея «Сети» | плейсхолдер со знаком с nefiktivnoe.ru | `d3d26966-9f16-4568-a855-ac58cfd30870` |
| `f5.jpg` | Пространство F5 | типографский плейсхолдер (аватар канала — узор, не логотип) | `7da73355-1517-4508-b4ec-b2a49b9602c7` |
| `audio_klub.jpg` | Аудио клуб | типографский плейсхолдер (логотип «ay!» есть только 160 px) | `69521d67-898e-46b8-a92a-115957d0b709` |

Одна картинка на много событий — это безопасно: очистка файлов удаляет только
файлы, на которые не ссылается ни одно событие
(`backend/internal/files/repository.go`), а замена обложки у события старый
файл не удаляет.

Фото из постов каналов сюда не берём: в условиях разрешения записано
«фотографии не копируем». Новую обложку — `render.py`, см. docstring.
