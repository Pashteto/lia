## Логика и решения прогона

- **Коды верификации — из прод-БД, не из почты:** `gateguard.users.email_verification_token`. Попутно вскрыло баг №8 (верифицированный админ с баннером «не подтверждена»).
- **Тестовое событие — полный цикл и уборка через продукт:** «QA-тест: Лекция о шрифтах» прошло черновик → публикация → заявка → приём → отклонение админом («тестовые данные»). Одним событием проверены три роли, уборка = часть теста.
- **Wrong-identity разобран до корня:** цепочка «пустой сабмит логина → нет ошибки → старая сессия организатора жива → владелец видит "Подать заявку" на своём событии → заявка от него». Это три отдельных дефекта (№4, №5 + отсутствие индикации аккаунта на пути записи).
- **Диагноз /map — через DOM:** консоль чистая; JS-зонд показал ymaps loaded, 42 узла, но карта h=0. Продублировано на десктопе ⇒ фикс один (высота внутреннего контейнера, не медиа-квери).
- **Ролевая изоляция:** отдельные аккаунты под зрителя и организатора, чтобы видеть пустые состояния и права каждой роли, а не смотреть из-под админа.
- **Уборка прода: UI где можно, SQL где надёжнее:** событие — через админ-флоу; RSVP/подписка — точечным SQL (UI-логин флейки из-за №4).

## Как упростить продукт — методы по ролям

**Зритель — убрать стену перед «Записаться»:**
1. Верификация *после* записи («подтвердите почту до события»), а не код перед CTA.
2. После верификации — возврат на событие и автозавершение записи.
3. «Записаться» прямо в карточке ленты.
4. Статус одной строкой: «Вы идёте · 26.08» вместо «ОК».

**Организатор — один хаб и переиспользование:**
1. «Я» = хаб «Участвую» / «Организую» + большая кнопка «Создать событие» (закрывает №10 без нового пункта навигации).
2. «Дублировать прошлое событие» — 80% созданий у регулярных лекториев.
3. Человеческие статусы: Черновик / На проверке / Опубликовано / Отменено.
4. Счётчик новых заявок в списке событий; owner-панель на published.

**Админ — сделать «Проверен» настоящим гейтом:**
- Новички публикуются через пре-модерацию, проверенные — сразу (чинит №2 и №3 разом, копирайт «до 24 часов» становится правдой). Уведомления о новых событиях в очереди («Ждут·9» лежали с 15.08).

**Все роли — честная обратная связь:**
- Ошибки форм логина/регистрации (самое дешёвое из критичного); фикс /map; прибрать мобильную шапку (бургер/короткий email); единые счётчики ленты/карты.
