# tg-ingest — сбор анонсов из Telegram-каналов

Первая версия полуавтоматического импорта: читает публичные превью каналов
(`t.me/s/<канал>`), отбирает посты, похожие на анонсы, вытаскивает дату, время,
цену и площадку и складывает **черновики на проверку**. Ничего не публикует.

## Почему именно превью, а не бот и не личный аккаунт

- Бот читает только те каналы, куда его добавил админ — для чужих каналов бесполезен.
- Вход под личным аккаунтом (MTProto) нарушает правила Telegram и грозит блокировкой аккаунта.
- Превью — обычные веб-страницы: аккаунт не нужен, блокировать нечего.

Подробное сравнение и юридическая часть: `docs/research/2026-09-17-telegram-ingest/README.md`.

## Где запускать

**Не на боевом сервере.** С него Telegram недоступен целиком (проверено 2026-09-17:
`api.telegram.org`, `t.me` и MTProto — таймаут). Запускать с Mac (под VPN) или с VPS вне РФ.

## Запуск

```bash
python3 ingest.py                    # три канала из channels.json, горизонт 45 дней
python3 ingest.py --days 30          # другое окно
python3 ingest.py --channel nefiktiv # один канал
python3 ingest.py --all              # включая уже импортированные (для проверки разбора)
```

Результат в `out/`:
- `candidates-<дата>.json` — готовые тела для `POST /api/v1/events` (всегда `status: draft`);
- `review-<дата>.md` — то же для чтения глазами: что нашлось, на что смотреть, что отброшено и почему.

Зависимостей нет, только стандартная библиотека Python 3.

## Что редактор доделывает руками

Сборщик намеренно НЕ пишет описание: тексты постов авторские, мы их пересказываем.
В `description` пусто — редактор пишет 2–4 предложения своими словами.

Проверять по заметкам в отчёте:
- **цена не найдена** — поставлено «бесплатно», в посте цены не было;
- **год не указан** — подставлен ближайший будущий;
- **дата по дню недели** («в эту пятницу») — вычислена от даты поста;
- **площадка из текста** — событие не на домашней площадке канала;
- **упомянут онлайн** — проверить формат.

## Как заводятся события

`candidates-*.json` содержит готовые `event_input`. Завести их можно из вкладки
браузера с админской сессией (`POST /api/v1/events` с токеном из `localStorage`),
как делалось 17.09. Обложка ставится отдельно через форму редактирования события:
у постов картинка своя, и права на неё принадлежат каналу — ставить только с разрешения.

После импорта дописать пост в `state.json` → `imported`, чтобы он не предлагался снова.

## Проверка качества (2026-09-18)

Прогон `--all` по трём каналам сверен с восемью событиями, заведёнными вручную
17.09: **дата, время и цена совпали у 8 из 8**. По дороге вылезли и исправлены
две ловушки, обе — из реальных постов:

1. «18.09   20:00» — дата через точку читалась как время (18:09). Различаем по
   второму числу: у времени это `00` или больше 12, у даты — `01`…`12`.
2. «19:30 — двери / 20:00 — начало» — подпись стоит после времени; ищем метку
   в своей строке с обеих сторон, двери в начало не берём.

Отбраковка на том же прогоне: 101 пост — прошедшие даты, посты без времени,
реклама подписок и дайджесты.

## Обложки (с 2026-10-01)

Событие без логотипа в афишу не выходит. Обложка берётся у площадки, иначе у
канала (`cover_file_id` в описании канала), иначе в отчёте «НЕТ ОБЛОЖКИ».
Строка «обложка» в отчёте теперь про эту картинку, а не про фото поста.
