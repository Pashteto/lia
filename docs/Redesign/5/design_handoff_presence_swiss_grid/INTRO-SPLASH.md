# Заставка «сообща» — спецификация для фронтенда

Первое открытие soobscha.ru: 3,6 с, играет один раз за сессию (`sessionStorage`), затем не показывается. Пропуск — тап/клик в любом месте или `prefers-reduced-motion` → сразу финальный кадр.

Референсы (открыть в браузере, скраббер внизу): `Soobscha Intro.dc.html` (1440×900), `Soobscha Intro Mobile.dc.html` (390×844). Исходники хореографии: `soobscha-intro.jsx`, `soobscha-intro-mobile.jsx` — читать как спецификацию таймингов, **не** переносить движок `animations-v3.jsx` в продукт.

## Реализация в проде
Чистый CSS (`@keyframes` + `animation-delay`), без библиотек. Один компонент `<IntroSplash>` поверх страницы (`position:fixed; inset:0; z-index` выше шапки), фон `#F2F0EC`. По окончании — `display:none`, шапка сайта под ним уже отрисована в том же месте, куда прилетает слово, поэтому стык невидим.

Шрифты: Archivo 900, Space Grotesk 400, JetBrains Mono 400 — те же, что у сайта; заставку не запускать до `document.fonts.ready`.

## Тайминги (секунды от старта)
| Бит | Окно | Что происходит |
|---|---|---|
| Scatter | 0 → 0.5 | 6 букв «с о о б щ а» появляются (opacity 0→1, 0.3 с каждая, стаггер 0.05 с) в разбросанных позициях с поворотом |
| Gather | 0.5 → 1.4 | буквы съезжаются в слово: translate/rotate → 0, 0.75 с, стаггер 0.025 с, easing `cubic-bezier(.76,0,.24,1)` (easeInOutQuart). Подпись «ВМЕСТЕ · ОБЩИМИ УСИЛИЯМИ» внизу, 0.7→2.1 с |
| Sign | 1.4 → 2.1 | линейка 2px под словом `scaleX 0→1` за 0.4 с (origin left); через 0.2 с адрес `SOOBSCHA.RU` слева и `МОСКВА · 2026` справа, моно, `#8A857C` |
| Open | 2.1 → 3.6 | слово летит в шапку (0.7 с, easeInOutCubic): font-size 220→15 px (моб. 84→17), позиция центр → (48,30) (моб. 18,58), трекинг −.06em→−.04em; линейка и адрес гаснут за 0.25 с. С 2.6 с — hairline шапки, навигация / таб-бар (0.35 с). С 2.8 с — контент ленты, opacity + translateY 18→0 (0.45 с) |

Easing: вход `cubic-bezier(.33,1,.68,1)` (easeOutCubic); сбор `cubic-bezier(.76,0,.24,1)`; посадка `cubic-bezier(.65,0,.35,1)`.

## Финальный кадр = первый экран сайта
Desktop: шапка «сообща» 15px/900/−.04em слева, навигация справа (9px, .14em, «События» подчёркнута 2px), заголовок ленты 72px, три модуля. Mobile: шапка «сообща» 17px + «МСК · 42», заголовок «Что смотреть на неделе» 30px, чипы фильтров, строки событий, таб-бар Лента · Подбор · Карта · Я.

## Полёт слова в шапку — приём
Одна нода. `left/top` и `font-size` интерполируются; центрирование снимается через `transform: translate(calc(-50% * k), calc(-50% * k))`, где k идёт 1→0 (в CSS — через `--k` кастомное свойство с `@property` или два ключевых кадра на transform). Трекинг анимировать нельзя нативно — допустимо оставить −.04em всё время.
